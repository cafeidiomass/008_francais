La course des verbes en -er

Pour lancer le jeu :
1. Décompresse le fichier .zip.
2. Ouvre le fichier index.html dans un navigateur.

Fichiers principaux :
- index.html : structure du jeu.
- style.css : apparence du jeu.
- script.js : déplacements, dé, pénalités, victoire et fenêtres du jeu.
- questions.js : liste des défis en français.
- assets/ : images et sons utilisés dans le jeu.

Pour ajouter ou modifier des questions :
Modifie le tableau QUESTIONS dans le fichier questions.js.
